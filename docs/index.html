MusicD Share Card for Android and Docker

Turns whatever is playing into a card worth sending — cover, title, artist, year, a few lines about the record and a Pitchfork score. Share it, save it, or post it to Discord with a webhook.

v0.50.0 Android 8.0+ Docker MIT licence Roon, Lyrion, Sonos, UPnP / DLNA

Download

Two builds, the same program. Run whichever suits the machine you already leave switched on.

Download the APK
musicd-share-card-0.50.0.apk

Android 8.0 (API 26) or newer. Your browser will warn you about downloading an APK, and Android will ask permission to install from this source — both are normal for an app that does not come from the Play Store.

Signing certificate (SHA-256)
e37c46d366db31124f231d68755cd9856b146e3f437fc5a99ff190701be84c21

Or run it in Docker

docker run -d --name musicd-share-card \
  --network host \
  -v "$PWD/sharecard-data:/data" \
  --restart unless-stopped \
  ghcr.io/meltface-80/musicd-share-card:latest

Then open http://<that machine>:8747 on anything on the network. For a NAS, a Pi, or the box Lyrion is already on — nothing to keep awake, and nothing to sideload.

--network host is not optional if you want it to find anything. SSDP, Roon’s SOOD and Lyrion’s broadcast are all multicast, and none of them cross a Docker bridge — on one, the container comes up healthy and finds nothing at all.

If that answers denied, the image is private, not missing. GitHub makes every package private the first time it is published and only the owner can change it. Until then, clone the repo and docker compose up -d --build — the same Dockerfile, built on your own machine.

Install

Three steps each way, once.

On Android

  1. Download and open the APK. Allow your browser to install unknown apps if Android asks — you can turn that back off afterwards.
  2. Open the app on the same Wi-Fi as your music. It finds the players itself; there is no address to type in.
  3. Optional — open it on your other devices. The app shows an address like http://192.168.0.42:8748. Open that in a browser on an iPhone, iPad or laptop and you get the same card. On iOS, Share → Add to Home Screen gives it an icon and opens it without browser chrome.

In Docker

  1. Make the data directory and give it to the container’s user. mkdir -p sharecard-data && sudo chown -R 10001 sharecard-data — it runs as uid 10001, not root. Skip it and the card still draws; it just forgets the Roon pairing, the webhooks and the metadata cache on every restart, and says so in the log.
  2. Run it with the command above, or docker compose up -d. Open http://<that machine>:8747 from anywhere on the network — the same page, served by the same code.
  3. If it finds nothing, it is almost always the network mode. Where host networking is not available — Docker Desktop on macOS and Windows — publish -p 8747:8747 instead and name your players’ addresses in SHARECARD_HOSTS, which needs no multicast.

Updating is done in the app, the same as on Android: the page says when there is something newer and Update downloads it, checks it and restarts into it. That replaces the app’s own code, not the image underneath — pull a new image now and then (docker compose pull && docker compose up -d) for JRE and OS updates. An update that will not start is thrown away on the next restart and the previous build comes back.

Features

🎵Whatever is playing

Roon, Lyrion Music Server, Sonos, or any UPnP / DLNA renderer on the network. It asks whichever one actually knows what the record is.

🖼️A card worth sending

Cover, title, artist and release year, with a few lines about the record and a Pitchfork score where there is one.

📤Share it anywhere

The Android share sheet, press and hold on an iPhone, or a plain download on a desktop.

💬Straight to Discord

Paste a webhook URL once and a button appears on the card. Tap it and the card is posted — under your own name and picture.

🔗Read it, or hear it

The Wikipedia article and the Pitchfork review behind the card, then Qobuz, TIDAL, Spotify, Apple Music, Amazon Music, Deezer and Bandcamp.

✨If you like this

Three acts worth hearing next, an album each. Hold a service chip to pick where they link — no settings screen.

📱One screen

Card, buttons, links and suggestions all fit, and the page does not scroll. The card stays until you ask for a new one.

🌐On your other devices

The same card opens in a browser on anything else on your Wi-Fi. Nothing to install on the iPad.

⬆️Updates itself

It notices a newer version, downloads it and asks Android to install it. No reinstalling by hand.

🔕Never polls

It asks a speaker what is playing when you open the page or press refresh, and at no other time.

🩺Says what went wrong

One button runs the whole search and reports what answered, what didn't, and the last crash if there was one.
